# 多媒体终端上位机 R291

黑白串口控制界面，115200 8N1，COM25；运行MediaControl.exe。
“换图语音”按钮或KEY3开启/关闭，板端默认开启，普通轮播新图显示后播放对应编号。
KEY4音量减、KEY5增；KEY9下一张、KEY11上一张；KEY10播放/暂停；KEY2节目模式。
节目模式使用原音轨与采样时间轴，不插入图片编号语音。音量/亮度0..10档。
底部字幕仍发送字符编码，FPGA固定字库查字/合成；B10控制开关。
原保存编辑文本在subtitle.txt，本次保留。语音素材固定存入易失位流，无运行时PC合成。
协议4保留，新增只读CMD0A快照，魔数53；旧板缺少该能力时禁用语音按钮。
720p60：74.25MHz像素，N6144/CTS74250。仅易失JTAG，无TF/Flash写入。
详见上级R291_CHANGE_REPORT.md及release_result.json，物理听感/完整IO签核未远端确认。

## 界面缩放

界面已改为DPI感知的表格响应式布局。默认960×720，最小840×700；拖大或最大化时，
串口选择、状态、操作按钮和字幕编辑区会随可用宽度按比例展开，窄屏内容可滚动。
首次启动会按当前屏幕工作区自动限制并居中，避免高DPI下窗口超出屏幕。

R292配套音频修复：主音轨断流平滑、语音Q3插值和抗混叠素材。新增只读CMD0B诊断，不改变现有界面与操作。用户当前音量7/语音关闭的偏好在板检后恢复。

## R298 音频模式

状态栏“音频：统一 / 逐视频”按钮可切换普通轮播背景音轨，状态来自板端查询回读。需要配套 R298 位流。统一模式换图不中断 WAV0，结束循环；逐视频按 FAT 扫描顺序选择 BMP N / WAV N，缺音轨静音，不回退播放其他音轨。节目模式保留已编排的 WAV0 时间轴。掉电后恢复默认统一模式。
